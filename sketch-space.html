What changes—and what stays fixed?

The activation position weights both the displacement and velocity supplied to each independent modal oscillator. The pickup reads a signed sum of that same field. Moving only the pickup leaves the vibrating state unchanged. A zero weight removes that mode from the output; an endpoint can be entirely silent.

One source pickup gain is retained across all positions. Quiet locations are not normalized upward. Every audition uses strength 0.35 and lasts four seconds, with a final 25 ms fade. The signed weights can change phase and balance as well as level. There is generally no position pair that reproduces the original non-spatial mixture exactly.
