Reviewer: Fable. Date: 2026-11-02. Page and worker syntax checked; module tests 3/3 with the sparse-array refusal added.

## Verdict: approve
- **Intake path**: a chosen local file goes through the bounded reader (abortable; the controller is aborted by the page's cancel path, so Escape, Cancel and pagehide all abort a pending read), then its text to the disposable preparation worker, which rechecks the 16 KiB bound on the encoded text, parses, and runs `reopenInverseCandidate`; a parse or validation failure is a plain refusal. The page is busy and the opener disabled while ringing; the generation token is checked after each await; `report` is replaced only after a successful reopen, so a failed intake keeps the current results and the prepared instrument, with the reason shown. A successful open clears the last touch (as a new search does) and the prepared instrument stays but cannot seed a comparison because its report is no longer the current one.
- **What a kept card says**: the recomputed residual and achieved resonances; the status mapped from the module's recomputed verdict (within tolerance, or "Kept instrument · outside tolerance", never "best found"); a line "Kept instrument. Declared discovery: seed N, M evaluations. Fit above is recalculated."; the connection map from its grove; "Prepare kept anatomy" through the ordinary prepare path. The target line says "Kept instrument for …" with the record's tolerance. The import disclosure sits under the target: local JSON up to 16 KiB, opening checks the instrument and target, preparation and listening remain separate choices.
- **Keeping**: "Keep this anatomy" on every card with a grove; a fresh discovery is kept with `keepInverseCandidate` and the current ISO time (the exact form the module requires); a reopened record is re-kept as the validated original (`report.savedRecord`), never as a fabricated search; the file is the canonical JSON offered as a local download (about 1 KiB), with the status line saying it holds the instrument and target without played touches. No upload, no automatic preparation or listening.
