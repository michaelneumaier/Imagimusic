# Review: continuation scheduling on the ensemble host (Astra, working tree: `src/grove/ensemble-host.js`, `tests/grove-ensemble-host.test.js`, `tests/grove-ensemble-continuation-live.test.js`)

Reviewer: Fable. Date: 2026-11-02. Twenty host and barrier tests plus the two live-processor parity tests pass here.

## Verdict: approve
- **A distinct scheduler**: `scheduleContinuation(steps, { handoffFrame })` is fresh-only (no sequence, no opening, no continuation), bounds the handoff to 20 s and the plan to 32 steps, requires non-decreasing integer offsets within the handoff, no Quiet, at least one strike, and validates every command on its part before posting anything; one base frame, own ids `continuation-<i>`, an immutable cloned plan kept with the barrier. The demonstration's `scheduleOpening` is unchanged and the two cannot mix.
- **Gating by evidence**: processed acknowledgements feed the barrier (Quiet accepted on the processor cancels the handoff), state snapshots feed its clock, completion emits a change; ordinary input is refused with reason `continuation` while waiting or aborted and clamped strictly beyond the completed boundary; a barrier throw on contradictory evidence reaches `fail`, as intended. Quiet from the host cancels before posting while delayed acknowledgements still count.
- **Metadata and provenance**: the clone getter exposes base frame, the captured common origin, the plan and the barrier snapshot (absolute frames, for the adapter's signed conversion at keeping); finished metadata survives park and a failed mount (origin restored when createNode fails) and clears only on a successful fresh mount or dispose.
- **Parity**: the live tests run the production processor and host under mocked Web Audio plumbing; remembered strike, contact and release, handoff, a personal strike and Quiet give one kept record whose reconstruction equals the captured processor samples exactly; the early-Quiet case keeps the accepted edges, closes the contact at the actual ending and accounts the later refused release. These are computation and capture tests, not device clearance, as Astra states.

No nits. The generator now returns a frozen `continuationPlan(record, { sampleRate })` of `{ steps, handoffFrame, sampleRate }` matching this scheduler's step shape (frame, part, command); the former unvalidated handoff helper is removed and its tests no longer read `renders/`.
