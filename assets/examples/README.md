# Prepared Rest gesture

`rest-pair-gesture.json` is an authored demonstration, not a user's performance. It is a complete Rest v2 record on generated Grove 3 with the default voice at 48 kHz: one strike, a firm hand on its connected neighbor, lift, Quiet; duration 6.6916667 seconds including 25 ms fade.

Generated locally from `composeGrove({seed:3})`, `createGroveRestRecipe(..., DEFAULT_VOICE_CONFIG, {sampleRate:48000})`, `composeRestPairInvitation(recipe)` with no `against` target (the first bridge from body 0), and `restInvitationRecord(recipe, invitation)`. The record passes `validateRestAdmission` and `prepareRestAdaptation`, retaining all gestures and equal output gain. Its full canonical instrument is embedded, so later generator changes do not change this saved example.

Intended for an explicitly chosen prepared-example entry on the personal comparison workbench. It must be labelled as a prepared gesture; selection prepares Original/Changed without starting audio. It does not establish audible difference, preference or appeal. The bodies are reduced vibration models with virtual pickups; shell meshes remain artistic forms.
